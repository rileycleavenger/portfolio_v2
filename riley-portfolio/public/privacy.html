Privacy Policy

Last updated: September 28, 2026

1. Scope

Reddit Stories Uploader ("the Tool") is a personal automation utility operated by Riley Cleavenger. It has exactly one user: the operator. This policy describes what data the Tool handles.

2. Data the Tool accesses

Through TikTok's Login Kit and Content Posting API, the Tool accesses only the operator's own TikTok account data:

  • Basic profile information (display name) to confirm the authorized account.
  • Video upload permissions to deliver the operator's own generated videos to the operator's own account inbox/drafts.

3. Data the Tool stores

The Tool stores TikTok OAuth tokens (access and refresh tokens) locally on the operator's own server, solely to maintain the authorized session. Tokens are never transmitted to any third party.

4. Data the Tool does not collect

The Tool collects no data from any other person. It has no public users, no analytics, no tracking, no cookies, and no advertising.

5. Data sharing

No personal data is sold, shared, or disclosed to any third party, except as required to interact with TikTok's API for the Tool's stated purpose, or as required by law.

6. Data retention and deletion

OAuth tokens are retained only while the Tool is in use and can be revoked at any time from the operator's TikTok account settings, which immediately ends the Tool's access.

7. Changes

This policy may be updated at any time. Material changes will be reflected in the "Last updated" date above.
